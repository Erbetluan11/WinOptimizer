Instalação rápida

  1. Abra o PowerShell como Administrador.
  2. Execute o comando:
irm https://raw.githubusercontent.com/Erbetluan11/WinOptimizer/main/install.ps1 | iex

O instalador baixa os arquivos do projeto para uma pasta temporária e abre o menu principal.

Atualização

Não há instalador tradicional. Ao executar o mesmo comando novamente, o instalador baixa a versão atual disponível na branch main.

Erro de download? Confirme que o repositório é público e que install.ps1, run.ps1, modules/ e config/ foram enviados para a branch main.
